# Project Nexus: Neuro-Symbolic Agentic Routing Engine

Project Nexus is an ultra-low latency, mathematically constrained C++23 systems-plane that implements zero-overhead tool routing for LLM agents. By integrating a hardware-accelerated **Semantic Lookaside Buffer (SLB)**, a thread-isolated **Token-Level Radix FSM**, a stride-aware **KV Cache Splicer**, **Redis-style $\mathcal{O}(1)$ probabilistic eviction**, and **NUMA-aligned asynchronous page-faulting**, Nexus bypasses the quadratic $\mathcal{O}(N^2)$ prefill compute wall of massive Model Context Protocol (MCP) tool schemas.

---

## The Problem: The Prefill Compute Wall

In agentic architectures, appending complete tool schemas (JSON descriptions often ranging from 10KB to 100KB) directly to the prompt context window incurs catastrophic quadratic processing delays. If an agent routes dynamically across multiple potential tools, standard systems must pay a full prefill compute wall on every turn. 

For example, prefilling a 12.5k token tool schema block on a modern GPU takes **~1.9 to 2.1 seconds**, destroying real-time conversational agent responsiveness.

## The Nexus Core Engine Paradigm

Nexus resolves the prefill compute penalty using an operating systems approach, treating tool schemas similarly to virtual memory pages loaded via a specialized Memory Management Unit (MMU):

1. **L1 Semantic Lookaside Buffer (SLB)**: Executes an ultra-fast ($<5\mu\text{s}$) SIMD-accelerated (AVX2/NEON) dot-product scan on quantized INT8 hidden states to identify candidate tools and prepends short 5-token semantic "scents" to prime vocabulary logits.
2. **Deterministic Radix Trie FSM**: Constrains tokens generated by the LLM down valid path routes at standard generation speeds, preventing schema parameter hallucinations and thread-isolated logit pollution.
3. **UMA/NUMA KV Cache Splicer**: Upon FSM resolution (`LEAF_REACHED`), the active context is truncated, and the pre-compiled `.atb` tool schema KV cache is hot-swapped into memory via POSIX `mmap` blitting (complemented by background page-faulting and NUMA interleaving policies). This reduces the prefill phase to a minor delta prefill over the user query tokens alone.

## Hardware-Aware Multi-Tenant Capabilities (Phase 21)

* **$\mathcal{O}(1)$ Amortized Probabilistic Cache Eviction**: Replaces $\mathcal{O}(N)$ linear scan lookup under exclusive write-locks with a Redis-style probabilistic random bucket sampling ($K=5$) algorithm, keeping critical lock-holding time under a microsecond even in 50k+ cached block systems.
* **Exception-Safe Poison Cleanup**: Resolves out-of-lock resource mapping throws safely. Async failures trigger direct cache map cleanup callbacks, fulfilling futures with custom runtime errors so waiting threads gracefully propagate failures instead of deadlocking the cache.
* **Background Page-Faulting & NUMA Affinity**: Relocates OS page-touching loops and GPU registration (`llama_register_host_memory`) to background thread workers (`std::async`). Applies page-aligned Linux NUMA memory interleaving (`MPOL_INTERLEAVE` via `SYS_mbind`) to maximize discrete GPU PCIe Gen4 DMA copy bandwidth.
* **Dynamic Hardware Telemetry**: Interrogates compiler backend libraries at runtime to distinguish Apple Metal UMA from Discrete CUDA configurations, logging platform-accurate metrics (e.g., `[Topology: UMA Zero-Copy]` vs. `[Topology: NUMA/PCIe Gen4]`).

## Build Instructions

### Prerequisites
* C++23 compliant compiler (Clang 16+, GCC 13+, or MSVC 2022+)
* CMake 3.25+
* Python 3.8+ with `nanobind` and `numpy`

### Compilation
Configure and compile all target libraries and Python bindings in a single pass:

```bash
# Configure build directory (Metal frameworks linked automatically on macOS)
cmake -B build -DCMAKE_BUILD_TYPE=Release

# Compile all targets
cmake --build build --config Release -j
```

## CLI Tools & Automation

### 1. Offline Schema Compiler (`nexus_kv_compiler`)
Prefills a JSON tool schema starting at a specific RoPE token offset (`base_pos`), extracts the cache, and writes it to `.atb` layout:
```bash
./build/nexus_kv_compiler \
  --model <path/to/model.gguf> \
  --schema <path/to/schema.json> \
  --output <path/to/output.atb> \
  [--base-pos <int>] \
  [--threads <int>] \
  [--verbose]
```

### 2. Block Verifier (`verify_atb`)
Asserts binary headers, magic bytes, layer dimensions, strides, and alignment limits of compiled `.atb` blocks:
```bash
./build/verify_atb <path/to/block.atb>
```

### 3. Ollama Resolver (`resolve_ollama_gguf.py`)
Queries local Ollama servers to locate physical GGUF models directly on disk for testing:
```bash
python3 scripts/resolve_ollama_gguf.py
```
